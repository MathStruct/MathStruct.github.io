Everything we build lives under the [MathStruct GitHub
organisation](https://github.com/MathStruct), is open source, and is documented in a published
vault of linked notes in which every page can be commented on. The [[index|front page]] explains
how the projects fit together.

Learn relations, not functions: implicit machine learning on factor graphs, in Julia.

[Vault](https://mathstruct.org/Lenticulum.jl/) ·
[API](https://mathstruct.org/Lenticulum.jl/api/dev/) ·
[Source](https://github.com/MathStruct/Lenticulum.jl) ·

### [[projects/sophia|Sophia]]: code

[Vault](https://mathstruct.org/Sophia/) · [Source](https://github.com/MathStruct/Sophia)
